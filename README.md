# General

Dependencies: git, stow

1. Clone this repo
2. `stow -v -t ~ .`

## Nvim

This is my personal config for nvim.

1. Install nvim Pre-built archive from https://neovim.io/doc/install/
2. clone this repo in `~/.config/`

## Added Plugins:

- knap: writing LaTeX
- toggleterm: easier switching between terminal
- claude-code integration
- LaziGit, requires LazyGit to already be installed (https://docs.rockylinux.org/10/books/nvchad/additional_software/)
  ```
  sudo dnf copr enable atim/lazygit -y
  sudo dnf install lazygit
  ```
## Configured Hotkeys:

Open Claude: CTRL + ,  
Run Python: SPACE + r + t
